# 隐私数据脱敏方案

## 目标

从当前项目和所有可访问的 Git 历史中移除个人电脑标识与个人提交邮箱。同时保留本机的开发配置文件，让当前电脑仍可使用它。

## 当前文件

- 停止跟踪 `.claude/settings.local.json`，并把它加入 `.gitignore`。文件保留在本机，不会删除。
- 将 `docs/archive/project-technical-doc-2026-07-30.md` 中的本机路径替换为 `<USER_HOME>`。

## 历史记录

- 重写此克隆中的所有本地分支和远程跟踪分支。
- 将个人作者和提交者邮箱替换为 GitHub noreply 地址，并使用通用贡献者名称。
- 从每个重写后的提交中移除本机配置文件。
- 将归档文档在历史版本中的本机路径全部替换为占位符。
- 验证后删除重写过程生成的备份引用，因为其中仍保留原始数据。

## 验证方式

- 扫描工作区和每一个可访问的历史版本，确认不再出现原本机路径和个人邮箱。
- 确认本机配置文件仍然存在，但 Git 已不再跟踪它。
- 确认项目测试通过。
- 本地扫描通过后，强制推送重写后的分支。

## 风险

重写历史会改变提交 ID。已有克隆的协作者需要丢弃旧历史或重新克隆。此操作无法删除仓库外部的副本、分叉、缓存或旧克隆。

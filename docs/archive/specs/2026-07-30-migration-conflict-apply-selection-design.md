# 迁移冲突复用选择设计

## 目标

导入迁移数据时，用户遇到多本候选书籍的冲突，不必为每条冲突重复输入同一个编号。用户可将本次选择应用到本次导入剩余的冲突。

## 交互

首次出现冲突时，显示自定义对话框，列出候选书籍和编号。对话框提供三个操作：

- `确定`：只将当前迁移书籍恢复到所选编号。
- `确定并应用到后续冲突`：恢复当前书籍，并在本次导入后续冲突中复用所选编号。
- `取消`：跳过当前冲突。

复用选择只存活于当前一次导入，不写入配置，也不会影响下一次导入。

## 边界

后续冲突的候选列表存在该编号时，系统自动选择对应候选书籍，不再显示对话框。候选数量不足，或复用编号无法对应候选时，系统重新显示对话框；用户可重新选择、继续复用，或取消。

这项功能按候选列表中的编号工作，不把某一本书的 ID 或名称强行套用到后续冲突。每条冲突仍由既有匹配逻辑生成自己的候选列表。

## 实现

在设置页的迁移导入流程中维护仅本次使用的复用编号。将现有的 `window.prompt()` 替换为返回“所选书籍”和“是否复用”的自定义 `dialog`。`resolveConflict` 优先尝试复用编号；无法使用时显示对话框并更新或清除复用状态。

## 测试

提取可独立测试的候选选择逻辑，覆盖：首次选择开启复用、后续同编号自动选择，以及候选数量不足时回退到对话框。现有迁移导出和来源文件测试继续运行。

# 迁移数据导出设计

## 目标

设置页只保留迁移数据导入和导出。导出时由用户选择是否包含正文和原文件，同时保留现有阅读数据、目录、书签、进度和书架顺序迁移能力。

## 方案

- 删除设置页上的配置导出、配置导入入口。
- 保留内部旧配置格式读写函数，避免历史代码调用时报错；它们不再作为新功能入口。
- 导出按钮打开原生对话框，提供“导出正文”和“导出原文件”两个复选项，默认不勾选，并提供取消和导出按钮。
- 选项分别映射到 `file.exportMigration()` 的 `includeContent` 和 `includeSource` 参数。
- 迁移格式继续使用 `treader-migration` v2。导入端保持兼容，缺少正文时仍可根据已有文件或路径恢复；完全没有正文时继续生成占位记录。
- 正文和原文件同时导出时允许内容重复，以保证新环境无原文件时也能立即阅读，并保留 EPUB 原始资源。

## 验证

- 用独立的纯函数测试验证四种选项组合只写入对应字段。
- 做 JavaScript 语法检查。
- 运行现有 Rust 测试，不执行打包。

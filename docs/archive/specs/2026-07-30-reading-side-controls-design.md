# 阅读页侧栏控制设计

## 目标

在桌面阅读页点击正文并打开控制面板时，将当前的顶部标题栏和底部工具栏改为旧版的左右侧栏布局。

## 范围

- 仅调整阅读页控制面板的 CSS。
- 宽度至少为 768px 时，左侧显示返回和更多操作，右侧纵向显示目录、书签、搜索和跳转。
- 宽度小于 768px 时，保留现有的顶部和底部工具栏。
- 不修改书架、设置页、阅读数据、翻页/滚动逻辑、目录和书签逻辑。

## 实现

现有宽屏阅读页已经有将控制栏旋转为侧栏的样式。将同一组布局规则扩展到 768px 及以上的阅读窗口，并放在现有宽屏规则之后，以覆盖 768px 到原宽屏阈值之间的上下工具栏样式。

## 验证

新增 Node 回归脚本，检查 CSS 同时具备 768px 断点、左右侧栏定位、标题隐藏和纵向工具按钮规则。再运行 JavaScript 语法检查和既有 Node 测试。

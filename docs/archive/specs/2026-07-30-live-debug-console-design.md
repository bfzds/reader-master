# 实时调试控制台设计

## 目标

把现有“显示调试控制台”开关扩展为轻量的实时日志查看器，帮助定位运行问题，同时不影响阅读页面、设置页面和迁移流程。

## 功能范围

- 开关打开后显示悬浮日志面板，关闭后移除面板。
- 捕获 `log`、`info`、`debug`、`warn`、`error` 五类控制台日志。
- 每条日志显示时间、级别和格式化后的参数；不同级别使用不同颜色。
- 面板支持滚动、清空日志和暂停自动滚动。
- 最多保留最近 500 条日志，超出后丢弃最早记录，避免日志面板占用过多内存。
- 保留原生 `console` 输出，不改变业务代码的日志行为。

## 交互与兼容

- 继续使用现有高级设置开关，不新增持久化配置。
- 日志面板使用固定悬浮层，不改变页面布局，也不阻止阅读区域操作。
- 打开面板后只查看此时开始采集的实时日志，不追溯控制台开启前的历史输出。
- 面板内部按钮和滚动区域可操作；日志正文不响应鼠标事件。

## 实现边界

- 只修改调试日志模块、必要的样式和技术文档。
- 不加入网络上报、日志导出、敏感信息脱敏或复杂筛选，留待后续需求。
- 采用测试先行，覆盖级别采集、参数格式化、数量上限和暂停滚动状态。

# tReader 更新日志

## 2026-07-29 — 新版功能优化与性能修复

本版本仅更新新版源码，旧版不再修改；发行版暂未打包。

### 书架与迁移

- 增加配置导入/导出兼容，支持恢复书籍信息、目录、书签和阅读进度。
- 记录书籍来源文件名及默认存储目录，便于后续恢复。
- 修复 TXT/GZ 书籍被错误提示为 EPUB 的问题。
- 文件夹刷新支持 TXT、GZ、EPUB，并修复占位书籍无法自动匹配的问题。
- 增加书架多选模式入口，支持全选、批量删除和退出多选。
- 删除源文件失败时保留书架记录，避免数据状态不一致。

### 性能与稳定性

- 文件夹刷新改为先读取文件信息，再按需读取实际书籍内容，降低内存和 IPC 开销。
- 大批量导入增加分批让出事件循环，减少界面长时间无响应。
- 优化备份导入重复检测，避免大量书籍导入时重复遍历。
- 修复文件夹权限在程序重启后失效的问题，增加 Electron/Tauri 重新授权流程。
- 增加文件夹路径校验、非法路径防护和端口占用提示。
- 修复 Tauri 窗口生命周期和安装版启动相关问题。
- Windows release 版本隐藏多余控制台窗口。

### 阅读与数据可靠性

- 修复编辑内容关闭窗口或切换书籍时可能未保存的问题。
- 修复编辑后目录、书签和阅读进度被清空的问题。
- 修复 EPUB 目录游标偏移。
- 修复 EPUB 源文件备份与恢复。
- 修复搜索结果正文高亮、同页多处高亮和远距离跳转后首次高亮问题。
- 统一旧版索引结构、日期、书签和备份数据的兼容处理。

### 功能调整

- 移除新版语言朗读功能及相关设置、阅读控制按钮和后台缓存引用。
- 保留翻页、滚动、目录、书签、搜索、跳转、编辑、自动滚屏和 TXT/GZ/EPUB 支持。
- 删除旧版数据导出改动，后续维护重点转向新版。

### 验证状态

- 已完成 JavaScript 语法检查。
- 已通过 `cargo check --manifest-path src-tauri/Cargo.toml`。
- 已进行新版开发模式人工测试，暂未执行发行版打包。
- 后续待确认朗读移除后的阅读、目录、搜索、书签和编辑回归测试。

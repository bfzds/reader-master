# EPUB 2 Directory Compatibility Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Import PixivBatchDownloader EPUB 2 books with their NCX directory and without duplicated directory-page chapters.

**Architecture:** Extend `readEpub()` in the existing parser so EPUB 3 `nav` remains preferred and EPUB 2 NCX is a fallback. Use OPF guide/navigation metadata to omit only navigation documents from extracted text, then persist the parsed explicit index through the existing import flow.

**Tech Stack:** Browser ES modules, DOMParser, JSZip, Node static server.

## Global Constraints

- Modify only the EPUB import path and its dedicated regression fixture.
- Do not add packages or alter EPUB export behavior.
- Retain MPL headers in existing source files.
- Keep EPUB 3 navigation support.
- Create a rollback script under `docs/rollback/` before completion.
